# Little Letters

Calm, premium alphabet learning for kids — DIY, offline-friendly PWA.

## Try it
- **GitHub Pages:** https://officialamve.github.io/little-letters/
- **Render:** https://little-letters.onrender.com

## Features
- English A–Z (hear, a/A toggle, progress)
- Hindi · Tamil · Kannada · Telugu · Malayalam vowel starters
- Write (finger trace) + printable A–Z sheet
- Songs · hear-game · letter→word match · memory (3 letters)
- Today’s 5 path · streaks · on-device save · PWA

## Local
Open `index.html` in Chrome, or `npx --yes serve .`

## Stack
Static HTML/CSS/JS · Web Speech API · localStorage · service worker. MIT.
