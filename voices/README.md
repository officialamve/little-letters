# Custom voices (free DIY)

Drop short MP3/OGG clips here, then name them to match words:

```
voices/en/a.mp3
voices/en/apple.mp3
voices/en/happy.mp3
voices/hi/अ.mp3
```

In the app, Hear prefers a matching file under `voices/` when present; otherwise it uses the browser voice.

Tips for friends recording:
- Quiet room, phone voice memo is fine
- One word or letter per clip
- Speak slowly and clearly, kid-friendly tone
- Export/share as .mp3 or .ogg
